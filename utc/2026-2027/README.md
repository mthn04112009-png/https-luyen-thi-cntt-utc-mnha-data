## 🛠️ Hướng dẫn sử dụng

1. **Clone repo** về máy:
   ```bash
   git clone <repo-url>
   ```
2. Mở `README.md` bằng trình soạn thảo hoặc xem trực tiếp trên GitHub.
3. Bấm vào liên kết ở bảng **Mục lục** để xem toàn bộ slide của từng môn.
4. Muốn thêm ảnh slide mới, chép URL ảnh vào thẻ:
   ```html
   <img src="URL_ANH" alt="Mô tả" width="85%">
   ```
   > Lưu ý: nếu URL có dấu `(` `)` thì đổi thành `%28` `%29` để ảnh hiển thị đúng.
