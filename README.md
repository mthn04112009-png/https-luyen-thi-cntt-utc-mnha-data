Xin chào, mình là **Hùng Anh**.

* 💻 **Ngành:** Khoa học máy tính

Repository này dùng để lưu lại quá trình học tập của mình. Không phải project xịn sò gì đâu 😭

> **Học → Code → Sai → Debug → Hiểu → Lưu lại → Quên → Mở repo ra xem lại** 💀
